# Web Screen Documentation

เอกสารชุดนี้อธิบาย business behavior ในระดับหน้าจอของฝั่ง Web เพื่อให้เข้าใจว่าแต่ละหน้าแสดงอะไร รับ input อะไร เรียกข้อมูลอย่างไร และมีข้อจำกัดหรือ action อะไรบ้าง

## หัวข้อที่ใช้ในแต่ละไฟล์

- เป้าหมายของหน้าจอ
- ผู้ใช้เป้าหมาย
- ข้อมูลที่ต้องโหลด
- องค์ประกอบหลักของ UI
- action หลักของผู้ใช้
- validation และ feedback
- empty / loading / error state
- ความสัมพันธ์กับ Backend
